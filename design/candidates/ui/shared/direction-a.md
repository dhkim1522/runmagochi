# 방향 a — 말랑 클레이 다듬기

> 지금 앱의 말랑 클레이(페이즈 2.5 승인, `docs/design/design-system.md`)를 출시 품질로 다듬는다. 정체성은 그대로, 소음만 걷어낸다.

## 아이디어

손에 쥐는 장난감 같은 클레이는 남기되, 지금 화면에서 모든 칸이 같은 두께 테두리·같은 립을 써서 위계가 평평한 문제를 푼다. **입체(테두리 + 립)는 누를 수 있는 것과 주인공(캐릭터 무대)에만** 주고, 읽기만 하는 정보는 평평한 판으로 낮춘다. 그러면 "누르는 것 = 도톰한 것" 이 한눈에 읽힌다.

## 색 (기존 토큰 그대로, 쓰임만 정리)

| 역할 | HEX | 쓰는 곳 |
| --- | --- | --- |
| 바탕 `cream` | `#FFF7ED` | 화면 배경 |
| 판 `surface` | `#FFFFFF` | 정보 카드(테두리 없이 또는 2px `line`) |
| 무대 `surface-soft` | `#FFEDD5` | 캐릭터 무대, 진행 막대 트랙, 선택 안 된 칩 바탕 |
| 테두리 `line` | `#FED7AA` | 누르는 것의 테두리 2~3px |
| 립 `line-strong` | `#FDBA74` | 흰 클레이 버튼·칩 아래 립 |
| 글자 `ink` | `#431407` | 본문·숫자 |
| 보조 글자 `ink-muted` | `#9A3412` | 라벨 (cream 위 6.9:1) |
| 주요 `primary` | `#F97316` + 글자 `#1C0A00` + 립 `#C2410C` | 시작·확인. 흰 글자 금지 |
| 보조 `accent` | `#2563EB` + 흰 글자 + 립 `#1E40AF` | 일시정지, 레벨 막대 |
| 달성 `success` | `#15803D` | 경험치 +, 목표 달성 |
| 코인 글자 | `#1E40AF` (`accent-deep`) | 코인 +N |

새 색을 만들지 않는다. 비율: 바탕 cream 70%, 흰 판 20%, 주황은 주요 버튼과 선택 칩·목표 막대에만.

## 글자

- 숫자·제목: **Jua** (Google Fonts). 본문·라벨: **Noto Sans KR** 400/500/700.
- 크기 단계는 토큰 그대로: 거리 120 (러닝 중), 요약 거리 64, title 28, title-s 22, stat 26, button 24, heading 18, body 16, label 14, caption 13.
- 다듬기: 라벨은 Noto Sans KR 14 700 `ink-muted`, 값은 Jua. 한 카드 안 글자 크기는 두 단계까지만. 숫자 단위(`km`)는 숫자 크기의 약 1/4, `primary-deep` 대신 `ink-muted`.

## 모양

- 모서리: 큰 판 24, 지표 판 20, 무대 32, 버튼·칩·막대 알약. 이 네 값만.
- **입체(3px `line` 테두리 + 6px 립)**: 버튼, 칩, 코인 칩, 캐릭터 무대. 누르면 4px 내려가고 립 2px.
- **평평한 판**: 지표 카드·경험치 행·구간 표·경로 카드는 흰 바탕, 테두리 없음 또는 2px `line`, 립 없음.
- 그림자 번짐 없음. 무대 바닥에 캐릭터 그림자는 `#FED7AA` 납작한 타원(번짐 없는 단색).
- 진행 막대: 알약, 트랙 `surface-soft`, 높이 12(목표)·10(레벨).
- 아이콘: 2px 둥근 선 아이콘(탭바·톱니·코인), 24px.

## 배치

- 홈: 위에서 `오늘 목표` 판(종류 선택은 알약 두 칸 분할 버튼, 칩 4개 한 줄) → 큰 캐릭터 무대(화면 폭 전체, 캐릭터 6배=192px, 이름·레벨·막대·남은 양을 무대 안 아래에, 코인 칩 왼쪽 위·톱니 오른쪽 위) → `시작` → 탭바.
- 러닝 중: 제목 → 거리 120 가운데 → 목표 줄 → 지표 3칸을 **한 장의 평평한 판에 세로 구분 없이 3열** → 달리는 캐릭터 무대(작게, 5배) → `일시정지`.
- 요약: 제목 + `공유` → 성장 무대(레벨 업 글자 + 4단계 캐릭터 + 행 3개를 무대 안에) → 날짜·이름 → 거리 64 → 지표 3칸 판 → 경로 판 → 구간 그래프·표 한 판 → `끝부분 잘라내기`(흰 클레이) → `확인`.
- 좌우 여백 20, 섹션 사이 24, 카드 안 16×20.

## 해야 할 것 / 하지 말 것

- 할 것: 누르는 것만 도톰하게. 캐릭터는 정수 배율(홈 6배, 러닝 5배, 요약 6배). 숫자는 Jua. 한 화면 주요 버튼 하나.
- 할 것: 경험치·코인 값은 오른쪽 정렬, 값 위 경험치(success)·아래 코인(accent-deep).
- 하지 말 것: 모든 판에 테두리 + 립(지금 앱의 소음). 새 색. 흰 글자 주황 버튼. 13px 미만 글자. 번짐 그림자·그라데이션.
- 하지 말 것: b(사각 계단 모서리·코발트·회색)나 c(연두·테두리 없는 큰 카드·초록) 쪽 모양을 섞기.
