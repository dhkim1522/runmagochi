01마스코트가 주인공

캐릭터는 사각 무대 위에 화면에서 가장 큰 그림으로 선다. 홈·요약 8배, 러닝 중 6배.

02러닝 중엔 숫자 하나

거리 128px 하나가 가장 크다. 흔들리는 현재 페이스보다 평균 페이스를 먼저 보인다.

03시작은 한 번의 탭

지난번 목표가 골라져 있어 홈의 큰 시작 버튼 하나로 바로 달린다.

04연두는 형광펜

연두는 누를 것과 선택된 것에만. 채워지는 막대·강조 글자는 초록. 화면마다 연두 버튼은 하나.

05실수 방지

종료는 길게 눌러야 된다. 늦게 눌렀으면 요약에서 끝부분을 잘라낸다.

06벌주지 않는 아바타

쉬는 날이 길어도 레벨은 줄지 않고 표정만 졸려진다. 빨강은 진짜 문제에만.

1

전체 화면 보드

사용자가 만나는 순서로 묶었어요. Android 16(Pixel 7 에뮬레이터, 라이트)에서 찍었고, 그림을 누르면 크게 봐요.

2

화면 흐름도

초록 실선은 러닝 한 번의 주 흐름, 회색 실선은 탭과 버튼 이동, 점선은 되돌아가는 길이에요. 기준은 docs/screens.md "화면 이동 흐름".

첫 실행은 한 번만캐릭터 소개·이름 짓기를 마치기 전에는 홈을 만들지 않아요. 권한 안내는 처음 시작을 누를 때 끼어들어요.
1km 미만은 홈으로길게 눌러 종료했는데 1km 미만이면 기록하지 않고 홈으로 돌아가 "1km 미만은 기록하지 않아요" 를 띄워요.
요약과 기록 상세는 같은 몸통러닝 직후 요약과 기록에서 연 상세는 같은 화면이에요. 기록에서 열면 성장 카드 대신 목표 줄만, 아래에 기록 삭제가 붙어요.
3

화면별 상세

번호는 화면 위 핀과 짝이에요. 긴 화면은 폰 안에서 스크롤해요. 요구사항 ID 는 docs/product.md 기능 요구사항 표.

4

와이어프레임 보드

같은 화면을 회색 블록으로 다시 그린 저충실도 보드예요. 배치와 위계만 남기고 색·그림·문구는 뺐어요.

주요 행동·숫자·선택됨 트랙·무대·선택 안 됨 카드

6

촬영 메모

어떻게 찍었는지와 찍으면서 본 것.

환경과 예시 데이터

  • Android: AVD runmagochi(Pixel 7, Android 16 · API 36), 릴리스 빌드 0.3.0 베타. 상태바는 시스템 데모 모드로 9:41 고정.
  • iPhone: iPhone 16 Pro 시뮬레이터(iOS 18.6), 디버그 빌드에서 디버그 띠를 끄고 찍음.
  • 예시 데이터: 2025-11 ~ 2026-10 러닝 33회를 백업 6판 형식으로 만들어 설정 › 가져오기로 넣음. 게임 규칙대로 경험치·코인·배지를 맞춰 Lv.9, 배지 9개, 코인 315 에서 시작.
  • 러닝 화면·요약·알림은 실제 러닝 2회를 가상 GPS(여의도 둘레 고리 경로)로 돌려 찍음. 3.60km(목표 3km 달성, Lv.10·새 외형 단계, 배지 목표 달성 30번), 1.56km(목표 10km 미달, 5분 넘게 멈춰 종료 예고 알림).
  • 빈 상태(기록·코인 내역)·첫날 홈·첫 실행·권한 안내는 새로 설치한 상태에서 찍음.

찍으면서 본 것

  • 확인 필요첫 러닝의 "목표 달성!" 알림이 러닝이 끝난 뒤에도 남아 12분 뒤 다음 러닝 중에도 보였어요(39 종료 예고 알림 화면).
  • 확인 필요끝부분 잘라내기 슬라이더의 트랙이 연두로 채워져요. 디자인 시스템은 연두를 막대 채움에 쓰지 않기로 했어요(밝은 바탕 위 1.2:1).
  • 관찰알림 작은 아이콘이 빈 동그라미로 보여요. 앱 아이콘 모양 단색 아이콘을 두면 알림창에서 더 잘 알아봐요.
  • 관찰카운트다운 동안 탭바가 보여요. 누르면 다른 탭으로 갈 수 있는지 확인이 필요해요.
  • 관찰공유 카드는 시스템 공유 창 미리보기에서 잘라냈어요. 오른쪽 아래 연필은 Android 의 편집 버튼이에요.
  • 관찰iPhone 요약의 직선 경로는 시뮬레이터가 위치 점을 직선으로 이어서 생긴 것이에요.
