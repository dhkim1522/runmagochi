## 옛 방향: 말랑 클레이 (페이즈 2.5 승인본)

> 결정 0029 로 바뀌기 전 방향이다. 아래 `*.dc.html` 시안과 `phase-3.5-screens/`·`phase-4-screens/`·`phase-5-screens/` 스크린샷, 구현 메모는 그때 모습 기록이다. 토큰 이름(`cream`·`accent`·립 등)도 옛 이름이다.

- 원본 캔버스: https://claude.ai/artifact/9XWdBkvcoJe1DmjXsbYAaC (2026-10-18 승인)
- 디자인 시스템: `docs/design/design-system.md`, 값은 `docs/design/tokens.json`
- 각 `*.dc.html` 은 캔버스 아트보드 원본이다(390px 폭 폰 화면). 색·크기 값은 토큰 HEX 그대로이니, 구현 때는 HEX 대신 같은 값의 토큰을 `lib/core/theme.dart` 에서 쓴다.
- 시안 속 도트 아바타는 자리표시다. 실제 캐릭터는 `design/character/` (작업 3·8).
- 문구는 현재 앱 그대로다. 아래 "달라지는 점" 만 새로 생긴다.
- `오늘 목표` 선택·`목표 진행` 줄·`목표 결과` 줄은 새 시안 없이 구현했다. 디자인 승인을 기다린다. 구현 화면 스크린샷은 `phase-3.5-screens/`(홈, 러닝 중, 목표 달성, 요약 달성·미달, 첫 실행 2장)에 있다.
- `Main`·`Summary`·`Settings` 시안 원본에 남은 `이번 주 목표` 카드·줄·설정 항목은 쓰지 않는다(결정 0018). 해당 화면은 아래 "달라지는 점" 과 스크린샷을 따른다.

### 공통

- 바탕 `cream`, 화면 좌우 여백 `space-5`(20), 화면 제목 `title`(Jua 28).
- 카드: `surface` + 3px `line` 테두리 + 아래 6px `line-strong` 립, 지표 카드 `radius-md`(20), 큰 카드 `radius-lg`(24), 아바타 무대 `surface-soft` + `radius-xl`(32).
- 주요 버튼: 높이 64 알약, `primary` + `on-primary` 글자 + 6px `primary-deep` 립. 보조(일시정지·재개): `accent` + `on-accent` + `accent-deep` 립.
- 탭바: 아이콘(선 아이콘) + 라벨 13, 선택 `primary-deep` 굵게, 나머지 `ink-muted`, 위 2px `line` 구분선.
- 숫자는 모두 Jua.

### 페이즈 4 구현 메모 (보상)

- 새 시안 없이 와이어프레임 `8 상점`·`6 보상`과 위 클레이 규칙으로 구현했다. 구현 화면 스크린샷은 `phase-4-screens/`(E2E 때 찍는다)에 둔다.

| 화면 | 달라지는 점 |
| --- | --- |
| 홈 | 무대 안 위쪽에 코인 칩(`CoinChip`): 코인 아이콘 + 잔액(`titleS`), 알약 `surface` 바탕·`line` 테두리. 누르면 상점으로 간다. 하단 탭이 `러닝`·`기록`·`아바타`·`상점` 4개. |
| 러닝 중·일시정지 | 자동 일시정지면 제목 `멈춰서 일시정지했어요` + 아래 `움직이면 이어져요`(caption, `ink-muted`). 버튼은 `재개`(accent)와 `일시정지`(보조)가 나란히. 사용자 일시정지는 기존 `재개` + `길게 눌러 종료`. |

### 페이즈 5 구현 메모 (확장)

- 새 시안 없이 위 클레이 규칙과 `lib/core/theme.dart` 토큰으로 구현했다. 모양 다듬기는 페이즈 6 에서 한다. 구현 화면 스크린샷은 `phase-5-screens/` 에 있다.

| 화면 | 달라지는 점 |
| --- | --- |
| 홈 | `오늘 목표` 카드 위에 `거리`/`시간` 선택. 거리는 `3km`·`5km`·`10km`·`직접`, 시간은 `20분`·`30분`·`60분`·`직접`(15~180분). 직접 입력한 값이면 `직접` 칩이 값을 보인다. |
| 러닝 중·일시정지 | 시간 목표면 `목표 N분` 줄과 진행 막대를 거리 목표와 같은 자리에 둔다. 달성하면 `목표 달성!`. |
| 요약 | 시간 목표 결과 줄은 거리 목표 줄과 같은 카드형 행(`목표 N분 달성` + `보너스 +N`). 구간 표 위에 구간 페이스 막대 그래프. 새로 받은 배지는 경험치 행처럼 카드형 행(배지 그림 + 배지 이름 + `코인 +N`). 오른쪽 위 `공유` 버튼이 카드 이미지를 만들어 시스템 공유 창을 연다. |
| 기록 | 제목 아래 `주`·`월`·`년`·`전체` 탭. 기간 이동 화살표, 합계(거리 `numberL`·러닝 횟수·평균 페이스·시간), 요일별·일별·월별·연도별 막대 그래프. 비어 있는 기간은 0 과 빈 막대. 아래 `최근 러닝` 목록. |
| 아바타 | 무대 아래 `업적` 입구. |
| 업적 | 뒤로 + 제목 `업적`. `개인 기록` 카드(최장 거리·최장 시간·최고 1km·최고 5km, 없으면 `-`). `배지 N / 12` 격자: 받은 배지는 컬러, 못 받은 배지는 같은 그림을 회색·흐리게. `다음 배지` 진행 줄. 배지 그림은 24×24 도트 메달을 2배로 그린다(sprite-spec 배지 절). |
| 설정 | `러닝 · 아바타` 묶음에 `음성 안내` 스위치(기본 켜짐). |
| 공유 카드 | 화면 밖에서 1080×1350 PNG 로 그린다. 장착한 아이템을 낀 아바타, 날짜, 거리, 평균 페이스, 시간, 목표 줄, 레벨업 줄, 앱 이름(`runmagochi`)을 담는다. |
