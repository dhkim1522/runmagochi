# 0007 segment 단위 저장과 복원

- 상태: 채택
- 날짜: 2026-10-16

## 배경

- 러닝 중 앱이 강제 종료되면 RunPoint 에 저장된 점으로 기록을 이어 간다.
- 점을 시간순으로만 이어 붙이면 일시정지 동안 이동한 거리가 기록에 들어간다.
- 점 시각으로 움직인 시간을 다시 계산하면 화면 타이머보다 작은 값이 나온다. 재개 직후 첫 점까지와 마지막 점부터 일시정지까지의 시간이 빠지기 때문이다. 복원 뒤 타이머가 뒤로 간다.

## 결정

- RunPoint 에 `segment` 번호를 저장한다. 시작·재개부터 일시정지까지 이어서 기록한 점 묶음이 segment 하나다.
- segment 번호는 0부터 빈 번호 없이 늘어난다. 점이 하나도 채택되지 않은 묶음은 번호를 받지 않는다.
- 진행 중 Run 의 움직인 시간을 10초마다 저장할 때 함께 갱신한다. 저장할 점이 없어도 갱신한다.
- 복원할 때는 segment 별로 점을 묶어 거리를 다시 계산한다. 거리는 같은 segment 안의 점 사이만 더한다.
- 복원한 움직인 시간은 Run 에 저장된 값을 그대로 쓴다.
- 저장된 segment 번호가 0부터 이어지지 않으면 복원하지 않는다.

## 결과

- 일시정지 동안 이동한 거리와 시간은 복원 뒤에도 기록에 들어가지 않는다.
- 일시정지 중에 종료되면 거리·1km 구간 기록·움직인 시간이 종료 전과 같다.
- 기록 중에 종료되면 마지막 저장 뒤 최대 10초의 점과 움직인 시간을 잃는다. 타이머는 저장된 값부터 이어진다.
- 복원한 러닝은 일시정지 상태로 시작하고, 재개하면 다음 segment 번호로 점을 저장한다.
