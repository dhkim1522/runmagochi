# 0040 워치 전용 앱(F34)은 1.0 이후 업데이트로 한다

- 상태: 채택
- 날짜: 2026-10-24

## 배경

- 사용자(2026-10-24): 러닝 앱이라면 애플워치·갤럭시 워치 연동이 필수다.
- 워치 연동은 두 단계다: ① 워치가 기록한 운동을 건강 앱(Apple 건강·Health Connect)에서 읽어 경험치로 반영(F15, 페이즈 9), ② 워치에서 바로 시작·종료하고 거리·페이스를 보는 전용 앱.

## 결정

- 1단계 F15 는 페이즈 9 에 넣는다. 워치로만 달려도 캐릭터가 자란다.
- 2단계 워치 전용 앱(F34)은 별도 앱(watchOS 는 SwiftUI, Wear OS 는 Kotlin 또는 Flutter) 개발이고 서명·심사도 따로라 1.0 이후 업데이트로 한다. 실측 전에 하지 않는다.

## 결과

- 1.0 은 건강 앱을 거쳐 워치 기록을 반영한다. 워치에서 앱을 직접 조작하는 기능은 이후 업데이트다.
