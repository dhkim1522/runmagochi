# 0037 다시 달리게 하는 기능과 연동을 1.0 전(페이즈 9)에 넣는다

- 상태: 채택 (결정 0023 의 건강 연동 백로그를 페이즈 9 로 당기고, F25 날씨 연동 범위를 넓힘)
- 날짜: 2026-10-24

## 배경

- UI/UX 검토 뒤 사용자가 신규 기능·연동 제안을 요청했고, 제안 목록에서 모두 골랐다(2026-10-24).
- 사용자가 더한 것: 날씨 연동 배경(날씨별 무대·위젯 배경 디자인 필요), 첫 실행에서 캐릭터가 바로 나오지 않고 알에서 태어나 동료 펫을 얻는 연출.
- 성공 기준이 "4주 동안 주 2회 이상 달린 비율 30%" 라서 앱을 열지 않아도 친구가 보이고, 혼내지 않으면서 다시 부르는 기능이 효과가 크다.
- 로컬 우선(결정 0001)을 지킨다. 서버가 필요한 소셜·로그인은 여전히 백로그다(결정 0032).

- 처음에는 1.0 전(알림·음성·GPX·부화)과 1.1(위젯·날씨·건강·새 친구·결산)로 나눴으나, 같은 날 사용자가 "실측 없이 할 수 있는 작업은 모두 지금" 으로 정했다. 표의 시기와 관계없이 모두 페이즈 9 에서 실측 전에 만든다.
- 순서: 작고 독립적인 것(GPX·음성·알림·결산) → 그림이 필요한 것(부화·날씨 배경) → 플랫폼 연동(위젯) → 스키마가 바뀌는 것(새 친구) → 권한 심사가 따르는 것(건강 연동).

## 결과

- 페이즈 9 범위가 실측 + 개선 + 신규 기능 9개로 늘어난다. 실측으로 화면이 바뀌면 다시 고친다.
- 날씨 연동은 인터넷 권한과 무료 날씨 API 가 필요하다. 개인정보 처리방침에 위치(대략)를 날씨 조회에 쓴다고 적는다.
- 건강 연동·위젯은 iPhone 무료 Apple ID 에서 HealthKit·App Group 이 제한될 수 있다. 안 되면 Android 로 먼저 확인하고 iPhone 은 페이즈 10 유료 계정 뒤에 켠다. 스토어 권한 신고는 페이즈 10.
