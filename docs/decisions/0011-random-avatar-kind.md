# 0011 캐릭터는 3종 중 무작위로 정해지고 바뀌지 않는다

- 상태: 채택
- 날짜: 2026-10-18

## 배경

- 페이즈 2.5 캐릭터 콘셉트로 병아리·젤리·도토리 3안을 그렸고(`design/character/concepts.png`), 하나를 고르는 대신 모두 쓰기로 했다.
- 기존 계획은 페이즈 3 첫 실행 화면에서 아바타를 직접 고르는 것이었다.

## 결정

- 캐릭터 종류(`Avatar.kind`)는 `chick`(병아리), `jelly`(젤리), `acorn`(도토리) 셋이다.
- 아바타를 처음 만들 때 셋 중 하나를 같은 확률로 무작위로 정하고, 이후 바꾸지 않는다. 바꾸는 화면을 두지 않는다.
- 페이즈 2 에서 만든 `kind = default` 아바타는 다음 실행 때 한 번 무작위로 정해 저장한다.
- 레벨·경험치·외형 단계 규칙은 종류와 무관하다. 종류는 그림만 바꾼다.
- 스프라이트는 종류별 폴더로 나눈다: `assets/sprites/<kind>/body/stage<n>_<action>.png`, `assets/sprites/<kind>/face/<mood>_<action>.png`. 종류마다 머리 모양이 달라 face 레이어도 종류별로 둔다. 같은 종류 안의 4단계는 머리·눈 위치를 맞춘다.
- 페이즈 3 첫 실행 화면은 "아바타 선택" 대신 "처음 만나는 캐릭터 소개·이름 짓기·주간 목표" 로 바꾼다.

## 결과

- 그림 양이 3배다(종류 × 4단계 × 동작 프레임 + 종류 × 표정).
- 사용자마다 다른 친구를 만나는 재미가 생기고, 지인 베타에서 종류별 반응을 비교할 수 있다.
- 마음에 들지 않는 종류가 나와도 바꿀 수 없다. 베타 의견에 따라 다시 검토한다.
