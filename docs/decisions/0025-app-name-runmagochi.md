# 0025 앱 이름은 런마고치로 간다

- 상태: 채택 (결정 0012 의 "-gotchi 계열 표현을 피한다" 를 대체)
- 날짜: 2026-10-21

## 배경

- 결정 0012 는 "-gotchi" 계열 표현을 피하고 이름 후보를 상표 검색으로 좁히기로 했다.
- 페이즈 5 에서 후보 6개를 조사했다(`docs/research/naming.md`). 상표(KIPRIS)는 도구로 조회하지 못해 모두 `미확인` 이다.
- 사용자는 개발 코드명 그대로 **런마고치(runmagochi)** 를 쓰기로 했다.

## 결정

- 앱 이름은 **런마고치 (runmagochi)** 로 한다.
- 다마고치(Tamagotchi)는 반다이의 등록 상표다. "~마고치" 가 상표 이의나 스토어 심사에서 문제가 될 수 있으므로, 출시 페이즈(9) 사람 확인에서 KIPRIS 로 "런마고치"·"마고치"·"Tamagotchi" 를 검색하고 충돌 여부를 본다.
- 충돌하면 조사한 후보(달롱·폴짝)를 대안으로 다시 본다.

## 결과

- 화면·스토어 자료에 런마고치를 쓴다.
- 상표 위험이 출시 직전에 드러날 수 있다. 그때 이름을 바꾸면 스토어 자료와 앱 표기를 고쳐야 한다.
