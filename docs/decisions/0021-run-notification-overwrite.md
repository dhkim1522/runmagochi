# 0021 러닝 진행 알림은 위치 서비스 알림에 같은 번호로 덮어쓴다

- 상태: 채택
- 날짜: 2026-10-21

## 배경

- 러닝 중 알림창에 거리·시간·목표 진행과 일시정지·재개 버튼을 보이기로 했다 (결정 0019).
- 위치 패키지(geolocator)가 기록 중 포그라운드 서비스 알림을 이미 하나 띄운다. 따로 알림을 하나 더 띄우면 알림창에 러닝 알림이 두 개 보인다.
- 위치 패키지는 알림 내용을 실행 중에 바꾸는 방법을 주지 않는다.

## 결정

- 위치 서비스 알림의 번호 `75415` 와 같은 번호로 우리 알림을 띄워 덮어쓴다. 안드로이드는 같은 앱의 같은 번호 알림을 채널이 달라도 교체한다.
- 우리 채널 `run_progress`: 중요도 낮음, 소리·진동 없음, 한 번만 알림, 지울 수 없음.
- 위치 서비스가 처음 띄우는 `러닝 기록 중` 알림은 첫 덮어쓰기 전까지 보이는 대체 문구로 둔다.
- 갱신은 상태가 바뀔 때 바로, 기록 중에는 화면 거리(10m 단위)가 바뀌었고 마지막 갱신에서 3초가 지났을 때만 한다. 시간은 알림의 크로노미터가 올린다.
- 알림 실패는 로그만 남기고 러닝은 계속한다.

## 결과

- 알림창에 러닝 알림이 하나만 보이고, 화면을 켜지 않고 진행을 확인한다.
- 위치 패키지를 올릴 때 `GeolocatorLocationService.ONGOING_NOTIFICATION_ID` 값이 `75415` 인지 확인한다. 바뀌면 `LocalRunProgressNotifier.notificationId` 를 맞춘다.
- 덮어쓰기가 동작하지 않는 기기가 확인되면 우리 알림을 위치 서비스 알림과 별도 번호로 두 개 띄우는 방식으로 바꾼다. 알림이 두 개 보이는 점을 감수한다.
