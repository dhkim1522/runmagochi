# 0001 로컬 우선 구조

- 상태: 채택
- 날짜: 2026-10-16

## 배경

1인 개발 초기 단계에서 서버와 인프라를 운영하면 비용과 관리 부담이 생긴다. 사용자 수가 적을 때는 서버가 주는 이점(기기 간 동기화, 보상 조작 방지)이 크지 않다.

## 결정

서버 없이 모든 데이터를 기기에 저장하고, 보상 계산도 앱 안에서 한다. 사용자가 늘어나면 서버로 옮긴다.

## 결과

- 로그인 기능이 필요 없다.
- 기기 변경 시 데이터는 OS 기본 백업과 파일 내보내기·가져오기로 옮긴다.
- 기기 조작으로 코인을 늘릴 수 있다. 혼자 하는 게임이고 유료 결제가 없어 피해는 본인에게만 간다.
- 서버 이전에 대비해 저장소 인터페이스, UUID, 생성·수정 시각, 코인 원장 방식을 쓴다. 상세는 [설계서](../architecture.md#서버-이전-경로).
- 유료 아이템을 도입하기 전에는 서버 검증이 반드시 필요하다.
