# 0003 보상 기능을 후속 페이즈로 둔다

- 상태: 채택
- 날짜: 2026-10-16

## 배경

러닝 기록이 정확하지 않으면 그 위에 얹는 보상도 의미가 없다. 반면 아바타 성장은 이 앱을 다른 러닝 앱과 구별하는 핵심이라 일찍 검증해야 한다.

## 결정

- 코인·상점·꾸미기(F9~F11)와 업적·배지(F19)는 후속 페이즈에서 개발한다.
- 아바타 성장(F7·F8)과 상태 반응(F18)은 MVP에 포함한다.

## 결과

- MVP 화면에서 상점·보상·업적 화면이 빠진다. 경험치 획득과 레벨업 연출은 러닝 요약 화면에 합친다.
- 꾸미기에 대비해 스프라이트 부위별 레이어 규격은 MVP에서 먼저 정한다.
