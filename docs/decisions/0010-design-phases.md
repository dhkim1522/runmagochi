# 0010 디자인을 기본(2.5)과 완성(6) 두 단계로 나눈다

- 상태: 채택
- 날짜: 2026-10-17

## 배경

- 페이즈 2까지 화면은 와이어프레임 수준이고 캐릭터는 코드로 만든 임시 도형이다.
- 캐릭터 품질을 높이는 수단(Aseprite, 픽셀 생성 AI, 이미지 생성 모델, 외주)은 대부분 유료이거나 결정할 게 많다.
- 기능이 다 정해지기 전에 출시 수준 디자인을 하면 기능 변경 때마다 다시 만들게 된다.

## 결정

- **페이즈 2.5 기본 디자인**: 무료 수단만 쓴다. Claude Design System·Design 캔버스로 디자인 시스템과 화면 시안을 만들어 적용하고, 캐릭터는 Claude 가 코드로 도트를 찍어 만든다. 목표는 제대로 동작하는 MVP 에 맞는 기본 품질이다.
- **페이즈 6 디자인 완성**: 모든 기능 페이즈(3~5)를 마친 뒤, 출시해도 될 수준으로 UI/UX·캐릭터·배경·아이템·아이콘을 다듬는다. 이때 에셋 수단을 비교 검토해 정하고, 수단에 맞춰 스프라이트 규격을 다시 확정한다.
- 스토어 출시는 페이즈 7 이 된다.
- 페이즈 2 작업 11(Aseprite 로 실제 도트)은 페이즈 2.5 의 코드 도트로 대체한다.

## 결과

- 유료 도구 없이 MVP 를 끝까지 만든다. 유료 수단은 다듬을 범위가 보이는 페이즈 6 에서 정한다.
- 디자인 값은 테마 파일, 캐릭터는 규격과 PNG 로 분리돼 있어 페이즈 6 은 교체·보강 위주다.
- 지인 베타의 "아바타 때문에 다시 달리고 싶은가" 의견은 기본 그림으로 받는다. 그림보다 성장 구조·재미를 보는 의견으로 해석한다.
