# 0019 러닝 알림에 실시간 진행을 보이고, 요약 공유 카드를 더한다

- 상태: 채택
- 날짜: 2026-10-21

## 배경

- 기획서는 "알림창에 진행 상황이 표시된다" 고 적었지만, 러닝 알림은 "러닝 기록 중 / 화면을 꺼도 기록이 이어집니다" 고정 문구다. Nike Run Club 은 알림창·잠금화면에서 시간·거리를 보고 일시정지할 수 있다.
- 러너는 휴대폰을 주머니·암밴드에 넣고 달린다. 화면을 켜지 않고 진행을 확인하는 수단이 알림뿐이다.
- 공유 기능이 없다. 도트 아바타가 자란 장면은 다른 러닝 앱에 없는 볼거리이고, 지인 베타·출시 홍보에 쓸 수 있다. 이미지는 기기에서 만들고 전송은 다른 앱이 맡아 서버가 필요 없다.
- 경로 선이 한 가지 색이다. Nike Run Club 은 페이스별 색으로 빠른 구간·느린 구간을 보여 준다.

## 결정

- **러닝 알림 (F20, 페이즈 4 첫 작업)**: 알림창·잠금화면에 거리·시간·목표 진행을 실시간으로 보이고, 일시정지·재개 버튼을 둔다. 구현 방식(위치 서비스 알림을 갱신할지, 별도 알림을 둘지)은 페이즈 4 계획에서 정한다.
- **요약 공유 카드 (F21, 페이즈 5)**: 요약 화면 공유 버튼으로 아바타·거리·시간·평균 페이스·목표 달성·레벨업을 담은 이미지를 만들어 OS 공유 창으로 보낸다. 페이즈 5 에서는 기능만 만든다.
- **페이즈 6-2**: 공유 카드 디자인을 캐릭터 확정 뒤에 다듬고, 경로 선을 페이스별 색으로 그린다.

## 결과

- 화면을 켜지 않고도 러닝 진행을 보고 멈출 수 있다.
- 공유 카드는 패키지 하나(`share_plus` 후보)가 늘어난다. 확정은 페이즈 5 계획에서 한다.
- 페이즈 4 범위가 작업 1개만큼 늘어난다.
