# 0035 실기기 테스트를 별도 페이즈 7.5 로 분리한다

- 상태: 채택 (결정 0026 의 페이즈 7 범위를 나눔)
- 날짜: 2026-10-23

## 배경

- 결정 0026 은 iOS 확장과 실기기 확인을 모두 페이즈 7 에 두었다.
- 페이즈 7 의 구현 작업(iOS 대응·설치·실측 안내문·베타 자료)은 끝났고 남은 것은 사람이 직접 달려 보는 확인뿐이다.
- 사용자(2026-10-23): 실기기 사람 테스트는 따로 하고, 테스트 뒤 소감·개선점을 리포트하고 수정해 버전 1.0 으로 출시를 결정하는 흐름도 좋다.

## 결정

- **페이즈 7**은 iOS 확장 구현(빌드·대응·설치, 실측 안내문 `docs/field-test.md`, 베타 자료)까지로 닫는다.
- **페이즈 7.5 실기기 테스트와 개선**을 새로 둔다. 범위: 페이즈 1~6 의 실기기 "사람 확인", Android·iPhone 30분 러닝 3회 실측, Android 지인 베타, 소감·개선점 리포트, 고칠 점 수정, 기준값 조정, 버전 1.0 후보 만들기. 완료 기준은 기존 페이즈 7 의 것과 같다.
- 순서: 7 → 7.5 → 8 산출물 정리 → 9 출시(1.0). 8 은 7.5 의 실측과 수정이 끝난 앱을 기준으로 한다(결정 0026).
- 출시 여부는 페이즈 9 에서 정한다. 하면 7.5 를 마친 1.0 으로 Google Play·App Store 에 동시에 낸다.

## 결과

- 페이즈 7 이 사람 일정과 무관하게 닫힌다.
- 실측·의견 수집에 걸리는 기간(지인 베타 2주 등)이 한 페이즈 안에 모인다.
