# 0002 원천 문서를 저장소에 둔다

- 상태: 채택
- 날짜: 2026-10-16

## 배경

Mac과 Windows PC를 오가며 작업한다. Claude Code의 대화 기록과 메모리는 PC마다 따로 저장되어 다른 PC로 넘어가지 않는다.

## 결정

기획·설계 문서의 원천은 이 저장소의 `docs/` 에 Markdown으로 둔다. 와이어프레임처럼 Markdown으로 옮길 수 없는 디자인 산출물만 claude.ai 아티팩트로 두고 링크한다.

## 결과

- clone 한 번으로 문서와 코드를 함께 받는다.
- 문서 변경이 코드와 같은 커밋 이력에 남는다.
- 다이어그램은 GitHub에서 그림으로 보이는 Mermaid로 쓴다.
- PC를 바꿀 때는 `HANDOFF.md` 를 갱신하고 push한다.
