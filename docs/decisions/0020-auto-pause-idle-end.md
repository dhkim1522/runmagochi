# 0020 멈추면 자동 일시정지하고, 오래 멈추면 예고 뒤 끝낸다

- 상태: 채택 (결정 0016 의 무활동 자동 종료를 대체)
- 날짜: 2026-10-21

## 배경

- 멈춘 러닝을 바로 끝내면 잠깐 쉰 러너의 러닝이 끝나, 다시 달리면 새 러닝이 된다. 5km 목표로 1km 를 달리고 멈췄다가 4km 를 더 달려도 어느 러닝도 목표를 채우지 못해 달성 보너스를 받지 못한다.
- 멈춘 시간이 기록 시간에 들어가 평균 페이스가 느려진다. Nike Run Club 은 멈추면 자동 일시정지하고 다시 달리면 이어 간다.
- 일시정지를 누른 채 잊으면 시작부터 6시간이 지나야 끝난다.

## 결정

### 자동 일시정지와 자동 재개 (F4)

- 기록 중 움직임이 없으면 자동으로 일시정지한다. 다시 움직이면(걷기 포함) 자동으로 재개한다. 같은 러닝으로 이어지므로 목표도 그대로다.
- 자동 일시정지와 사용자 일시정지는 다른 상태다. 움직임으로는 자동 일시정지만 풀린다. 사용자 일시정지는 사용자가 재개한다.
- 자동 일시정지 중 화면과 알림은 재개와 `일시정지` 버튼을 둔다. `일시정지` 를 누르면 사용자 일시정지로 바뀌어 5분 자동 종료 대신 1시간 규칙을 따른다.
- 자동 일시정지 중 시간은 움직인 시간·평균 페이스에 넣지 않는다.
- 빠른 이동 중이면 자동 일시정지하지 않는다. 마지막 빠른 점 뒤 10초가 지나기 전에는 멈춘 것으로 보지 않으며, 빠른 이동 자동 종료(시속 30km 30초)가 맡는다. (결정 0033 이후: 받아들이기를 미룬 빠른 점 뒤 10초, 탈것 의심이 맡는다)
- 판정 기준(초안, 실측으로 조정): 10초 동안 받아들인 점이 없거나 이동이 5m 미만이면 멈춤, 10초 안에 10m 이상 움직이면 다시 움직임. GPS 가 제자리에서 흔들려도 재개되지 않게 정확도 거름을 통과한 점만 쓴다.

### 오래 멈추면 예고 뒤 종료

- 자동 일시정지가 **5분** 이어지면 진동과 함께 `움직이지 않으면 러닝을 마쳐요` 알림을 **30초** 카운트다운으로 띄운다.
- 그 사이에 움직이거나 알림·화면에서 재개하면 이어 달린다. 끝까지 멈춰 있으면 러닝을 끝낸다.
- 사용자 일시정지가 **1시간** 이어져도 같은 예고 뒤 끝낸다. 이때 알림은 `일시정지가 길어 러닝을 마쳐요` 이고 재개만 안내한다(움직여도 풀리지 않는다).
- 끝 시각은 기록이 멈춘 시각이다. 자동 일시정지는 마지막으로 움직인 점, 기록 중에 사용자 일시정지를 누르면 누른 시각이다. 자동 일시정지에서 사용자 일시정지로 바꿔도 처음 멈춘 시각을 유지한다. 멈춰 있던 시간은 기록·보상에 들어가지 않는다.
- 시작부터 6시간 상한과 빠른 이동 자동 종료(시속 30km 30초)는 그대로다. (빠른 이동 자동 종료는 결정 0033 의 탈것 의심으로 바뀌었다. 점이 30초 없으면 자동 일시정지가 신호 끊김으로 바뀐다)

### 목표 도달

- 목표에 닿아도 기록은 계속한다(결정 0018 그대로). 목표를 채우고 멈추면 자동 일시정지 → 5분 → 예고 → 종료로 끝나고, 끝 시각은 마지막으로 움직인 점이다.

### 시점

- 페이즈 4 앞부분에 러닝 알림(F20, 결정 0019)과 함께 만든다. 예고는 높은 중요도의 별도 알림(번호 1001)으로 띄우고, 러닝 진행 알림(번호 75415)은 그대로 둔다.

## 결과

- 잠깐 쉬어도 같은 러닝으로 이어 달려 목표를 채울 수 있고, 평균 페이스가 쉰 시간에 늘어지지 않는다.
- 편의점에 들르거나 신호를 오래 기다려 5분을 넘기면 러닝이 끝난다. 오래 쉴 때는 사용자 일시정지를 쓴다.
- 일시정지를 잊어도 1시간 안에 끝난다.
- 자동 일시정지 판정은 GPS 품질에 달려 있어 실기기(페이즈 7)에서 기준값을 다시 본다.
