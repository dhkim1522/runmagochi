# 0020 멈추면 자동 일시정지하고, 오래 멈추면 예고 뒤 끝낸다

- 상태: 채택 (결정 0016 의 무활동 자동 종료를 대체)
- 날짜: 2026-10-21

## 배경

- 무활동 자동 종료는 받아들인 위치 점이 10분 없으면 러닝을 바로 끝낸다. 힘들어 잠깐 멈춘 러너도 러닝이 끝나, 다시 달리면 새 러닝이 된다. 5km 목표로 1km 를 달리고 멈췄다가 4km 를 더 달려도 어느 러닝도 목표를 채우지 못해 달성 보너스를 받지 못한다.
- 멈춘 시간이 기록 시간에 들어가 평균 페이스가 느려진다. Nike Run Club 은 멈추면 자동 일시정지하고 다시 달리면 이어 간다.
- 일시정지를 누른 채 잊으면 시작부터 6시간이 지나야 끝난다.

## 결정

### 자동 일시정지와 자동 재개 (F4)

- 기록 중 움직임이 없으면 자동으로 일시정지한다. 다시 움직이면(걷기 포함) 자동으로 재개한다. 같은 러닝으로 이어지므로 목표도 그대로다.
- 자동 일시정지와 사용자 일시정지는 다른 상태다. 움직임으로는 자동 일시정지만 풀린다. 사용자 일시정지는 사용자가 재개한다.
- 자동 일시정지 중 시간은 움직인 시간·평균 페이스에 넣지 않는다.
- 판정 기준(초안, 실측으로 조정): 10초 동안 받아들인 점이 없거나 이동이 5m 미만이면 멈춤, 10초 안에 10m 이상 움직이면 다시 움직임. GPS 가 제자리에서 흔들려도 재개되지 않게 정확도 거름을 통과한 점만 쓴다.

### 오래 멈추면 예고 뒤 종료

- 자동 일시정지가 **5분** 이어지면 진동과 함께 "움직이지 않으면 러닝을 마칩니다" 알림을 **30초** 카운트다운으로 띄운다.
- 그 사이에 움직이거나 알림·화면에서 재개하면 이어 달린다. 끝까지 멈춰 있으면 러닝을 끝낸다.
- 사용자 일시정지가 **1시간** 이어져도 같은 예고 뒤 끝낸다.
- 끝 시각은 마지막으로 받아들인 점으로 당긴다. 멈춰 있던 시간은 기록·보상에 들어가지 않는다.
- 시작부터 6시간 상한과 빠른 이동 자동 종료(시속 30km 30초)는 그대로다.

### 목표 도달

- 목표에 닿아도 기록은 계속한다(결정 0018 그대로). 목표를 채우고 멈추면 자동 일시정지 → 5분 → 예고 → 종료로 끝나고, 끝 시각은 멈춘 순간으로 당겨진다.

### 시점

- 페이즈 4 앞부분에 러닝 알림(F20, 결정 0019)과 함께 만든다. 예고 카운트다운이 같은 러닝 알림을 쓴다.

## 결과

- 잠깐 쉬어도 같은 러닝으로 이어 달려 목표를 채울 수 있고, 평균 페이스가 쉰 시간에 늘어지지 않는다.
- 편의점에 들르거나 신호를 오래 기다려 5분을 넘기면 러닝이 끝난다. 오래 쉴 때는 사용자 일시정지를 쓴다.
- 일시정지를 잊어도 1시간 안에 끝난다.
- 자동 일시정지 판정은 GPS 품질에 달려 있어 실기기(페이즈 7)에서 기준값을 다시 본다.
