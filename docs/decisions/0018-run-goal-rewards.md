# 0018 오늘 목표를 정하고 달리며, 목표 달성으로 보상을 나눈다

- 상태: 채택 (결정 0016 의 "러닝 삭제는 경험치를 무른다" 를 대체)
- 날짜: 2026-10-20

## 배경

- 지금은 시작 버튼을 누르면 목표 없이 달린다. 러닝별 목표(F6-2)는 후속 범위였다. NRC 처럼 오늘 뛸 목표를 고르고 바로 시작하는 흐름이 더 쓰기 쉽다.
- 보상은 달린 거리만으로 정해져, 목표를 채운 러닝과 못 채운 러닝이 같은 보상을 받는다. 목표를 채우고 싶은 동기가 약하다.
- 주간 목표·연속 달성 주수·주간 알림이 홈과 첫 실행을 복잡하게 만든다. MVP 에는 오늘 목표 하나면 충분하다.
- 러닝을 지우면 경험치를 물러 레벨이 내려갈 수 있다. 사용자가 기록을 지우는 이유는 대부분 정리이지 노력을 취소하려는 것이 아니다. 가짜 러닝은 지울 때가 아니라 기록할 때 막아야 한다.
- 위치 점의 튀는 값 거름(시속 25km)은 직전에 받아들인 점과 비교한다. 차를 타면 점이 계속 버려지다가, 신호 대기 등으로 평균 속도가 기준 밑으로 내려가는 순간 먼 점이 한 번에 받아들여져 차로 간 거리가 기록된다.

## 결정

### 오늘 목표

- 홈에서 오늘 목표 거리를 고르고 시작한다. 3·5·10km 를 한 번에 탭하거나 직접 입력한다(3~42km). 최소 3km 다.
- 기본값은 지난번 목표이고, 처음은 3km 다. 홈을 열고 시작 버튼만 누르면 바로 달린다.
- 목표 없이 달리는 선택지는 없다. 시간 목표·레이스는 후속 범위다.
- 러닝 중 거리 아래에 목표 진행을 보여 준다. 목표에 닿으면 진동과 "목표 달성!" 표시를 하고 기록은 계속한다. 종료는 사용자가 한다.

### 보상

- 러닝이 끝나면 한 번에 계산한다.
- **거리 보상**: 실제 달린 거리로 준다. 경험치 1km당 10 (지금 규칙 그대로).
- **달성 보너스**: 목표를 채우면 더한다. 경험치 = 목표 거리 1km당 5.
  - 10km 목표로 5km: 거리 50, 보너스 없음 → 50
  - 5km 목표로 5km: 거리 50 + 보너스 25 → 75
  - 5km 목표로 7km: 거리 70 + 보너스 25 → 95
- 달성 판정 거리는 경험치를 받는 거리다. 빠른 구간(1km 구간 페이스 2분30초보다 빠름)은 빼고 판정한다.
- 요약 화면은 달성과 미달을 다르게 보여 준다.
- 코인도 같은 구조로 준다(거리 보상 + 달성 보너스). 수치는 페이즈 4 에서 정한다.
- 경험치 수치는 초안이며 실측·베타로 조정한다.

### 주간 목표 제거

- 주간 목표 설정, 진행률, 연속 달성 주수, 주간 달성 보너스, 금요일 주간 목표 알림을 MVP 에서 뺀다. 후속 확장 기능으로 둔다.
- 이미 받은 주간 보너스 경험치는 그대로 둔다. 저장된 주간 목표 값은 지우지 않고 쓰지 않는다.
- 기록 화면의 "이번 주" 거리 합계는 남긴다(F5).
- 첫 실행은 캐릭터 소개·이름 짓기 2장으로 줄인다.

### 삭제와 잘라내기

- **러닝 삭제는 보상을 무르지 않는다.** 기록 목록과 거리 합계에서만 뺀다. 경험치·레벨·코인은 그대로다.
- **끝부분 잘라내기는 보상을 다시 계산한다.** 잘라낸 구간은 달리지 않은 구간이므로 새 거리로 거리 보상과 목표 달성을 다시 정한다. 경험치가 줄 수 있다.

### 빠른 이동 자동 종료

- 연속한 두 위치 점 사이 속도가 시속 30km 를 넘는 상태가 30초 이어지면 러닝을 자동으로 끝낸다.
- 끝 시각은 빨라지기 전 마지막으로 받아들인 점으로 당긴다. 빠른 이동 구간은 기록에도 보상에도 들어가지 않는다.
- 알림과 요약 이동은 지금의 자동 종료(종료를 잊은 러닝)와 같고 문구만 다르다.
- 막히는 도심 버스처럼 시속 30km 를 넘지 않는 차량은 걸리지 않는다. 걸음 센서 판별은 출시 페이즈(페이즈 9, 결정 0022)에서 한다.

## 결과

- 시작이 "목표 하나 고르고 시작" 으로 단순해지고, 목표를 채울 동기가 생긴다.
- 목표를 못 채워도 달린 만큼은 자란다. 보너스만 받지 못한다.
- 주간 알림이 없어져, 다시 앱을 열게 하는 장치는 아바타 표정만 남는다. 다른 알림은 베타 의견을 보고 정한다.
- 레벨·외형 단계 경계의 누적 거리 환산이 바뀐다(주간 보너스 대신 달성 보너스 기준).
- 차가 시속 30km 이상으로 달리면 30초 안에 러닝이 끝난다. 빠른 러너는 시속 30km(1km 2분)에 닿지 않으므로 잘리지 않는다.
