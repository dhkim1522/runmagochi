# 0039 새 친구 입양·도감(F31)은 캐릭터를 늘린 뒤 추후 업데이트로 미룬다

- 상태: 채택 (결정 0037 의 F31 을 페이즈 9 에서 뺌)
- 날짜: 2026-10-24

## 배경

- 사용자(2026-10-24): 새 친구를 맞이하고 이전 친구를 도감에 남기려면 캐릭터를 지금보다 더 많이 만들어야 한다. 3종뿐이라 도감이 비어 보이고 맞이할 친구도 한정적이어서 시기상조다.
- 설계 논의에서 정한 규칙(보존): 새 친구는 Lv.1부터, 이전 친구는 도감에 레벨·누적 거리와 함께 남김, 열리는 시점은 마지막 성장 단계(Lv.20) 도달 뒤. 러닝 기록·코인·배지·아이템은 계속 이어진다.

## 결정

- F31 은 백로그로 둔다. 캐릭터 종류가 늘어난 뒤 페이즈를 꺼내 한다.
- 만들 때 필요한 것: 아바타 여러 행(현재 친구 표시), 경험치를 현재 친구 기준으로 세기(스키마·백업 판 변경), 도감 화면, 부화 연출(F33) 재사용.

## 결과

- 페이즈 9 범위는 신규 기능 8개(알림·음성·GPX·결산·부화·날씨·위젯·건강 연동)가 된다.
