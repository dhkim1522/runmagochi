# 0027 1km 미만 러닝은 저장하지 않는다

- 상태: 채택
- 날짜: 2026-10-21

## 배경

- 목표는 항상 정하고 시작하지만(결정 0018), 시작하자마자 끝내면 0m 러닝이 기록에 저장된다.
- 이런 러닝도 `첫 러닝`·`3일 연속`·`새벽 러너` 배지를 채워 최대 150 코인을 받는다.
- 시험 삼아 켰다 끈 러닝이 기록·통계에 쌓인다.

## 결정

- **저장 기준**: 기록 거리가 1km 미만인 러닝은 끝낼 때 저장하지 않는다. 진행 중 기록을 지우고 `1km 미만은 기록하지 않아요` 를 알린다. 경험치·코인·배지도 없다.
  - 사용자 종료, 자동 종료(오래 멈춤·빠른 이동·6시간), 강제 종료 뒤 복원 모두 같은 기준이다.
- **배지 기준**: `first_run`·`streak_3`·`dawn` 은 경험치 거리(빠른 구간 제외, 10m 반올림) 1km 이상인 러닝만 센다.

## 결과

- 짧게 몸을 풀거나 1km 전에 멈춘 러닝은 기록에 남지 않는다.
- 기록·통계·배지에 시험 러닝이 섞이지 않는다.
