# 로드맵

> 페이즈별 개발 범위와 완료 기준. 각 페이즈는 완료 기준을 통과해야 다음으로 넘어간다.

## 현재 위치

**페이즈 0 준비**. 기획·설계 문서는 작성됐고, 기술 스택과 페이즈별 기능 단위가 미결정이다.

## 페이즈

| 페이즈 | 범위 | 완료 기준 |
| --- | --- | --- |
| 0 준비 | 분석, 와이어프레임, 기획·설계 문서, 기술 스택 결정 | 기술 스택과 페이즈 1 범위 확정 |
| 1 이후 | TBD | TBD |

## 확정된 제약

- 러닝 기록(F1~F4)이 가장 먼저 동작해야 한다. 나머지 기능은 모두 기록 위에 얹힌다.
- 보상 기능은 후속 페이즈로 둔다. 근거는 [결정 0003](decisions/0003-defer-rewards.md).
- 서버는 사용자가 늘어날 때 도입한다. 그 전까지는 로컬 우선으로 개발한다. 근거는 [결정 0001](decisions/0001-local-first.md).
- 실제 UI 디자인과 캐릭터 에셋은 기능 개발 뒤에 적용한다. 개발 중에는 와이어프레임 수준의 화면과 임시 스프라이트를 쓴다.
