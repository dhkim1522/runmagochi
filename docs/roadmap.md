## MVP 범위

[기획서](product.md#기능-요구사항)의 MVP 열이 '포함'인 기능이다.

- **러닝 기록**: F1~F3, 기록 수정(F16), 기록 신뢰성(F17)
- **기록 관리**: 목록·상세·주간 합계(F5)
- **목표**: 주간 목표(F6)
- **아바타**: 성장(F7), 러닝 중 아바타(F8), 상태 반응·로컬 알림(F18)
- **백업**: 파일 내보내기·가져오기(F12)

## 확정된 제약

- 러닝 기록(F1~F3)이 가장 먼저 동작해야 한다. 나머지 기능은 모두 기록 위에 얹힌다.
- 코인·상점·꾸미기·업적은 후속 페이즈다. 근거는 [결정 0003](decisions/0003-defer-rewards.md).
- 서버는 사용자가 늘어날 때 도입한다. 근거는 [결정 0001](decisions/0001-local-first.md).
- 실제 UI 디자인과 캐릭터 에셋은 기능 개발 뒤에 적용한다. 개발 중에는 와이어프레임 수준의 화면과 임시 스프라이트를 쓴다.
