# Card

테두리 없는 흰 판. 정보는 모두 카드 안에 둔다.

- `surface` 바탕, 테두리 없음, 그림자 없음(또는 아주 옅은 한 겹). 바탕 `background` 와 톤 차이로 떨어진다.
- 모서리 `radius-lg` 24, 작은 카드(지표 3칸) `radius-md` 20, 마스코트 판 `radius-xl` 28.
- 안쪽 여백 `space-5` 20. 카드 사이 `space-3` 12.
- 지표: 라벨 `label`(`ink-muted`), 값 `stat` 22/800 고정폭 숫자.
- 보상 줄: 경험치·보너스는 `primary-deep` 17/800, 코인은 `coin` 14/700. 배지 코인(`코인 +200`)도 같은 크기·굵기로 줄이지 않는다.
- 행 사이는 선 대신 간격(18).
