# EmptyState

목록이 비었을 때와 불러오지 못했을 때 보이는 카드.

- 흰 카드(`surface`, `radius-lg`), 안쪽 여백 위아래 `space-8` 32 · 좌우 `space-5` 20. 가운데 그림 40, 아래 `space-3` 12 띄우고 문구 `body` 17/500 `ink-muted`, 가운데 정렬.
- 그림은 앱 그림을 쓴다(기록은 기록 막대 탭 아이콘, 코인 내역은 코인). 크기는 40.
- 불러오기 실패(`EmptyState.error`)는 같은 카드에 느낌표 동그라미(`ink-muted`)와, 필요하면 문구 아래 `space-5` 띄워 `다시 시도` 버튼. 사용자가 고칠 문제가 아니라 `danger` 를 쓰지 않는다(벌주지 않게).
- 문구는 화면의 기존 문구 그대로(`아직 기록이 없어요`, `달리면 코인이 쌓여요`, `내역을 불러오지 못했어요`).
