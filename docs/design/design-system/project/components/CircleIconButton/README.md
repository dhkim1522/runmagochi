# CircleIconButton

머리줄의 작은 행동(뒤로, 설정)을 맡는 흰 동그라미 아이콘 버튼.

- 48×48 `surface` 동그라미, 아이콘 24 `ink`. 테두리·그림자 없음.
- 스크린 리더에는 이름(`뒤로`, `설정`)으로 읽힌다.
- 누르면 `duration-press` 80ms 로 0.97 까지 작아졌다 돌아온다. 애니메이션 줄이기면 누른 동안만.
- 비활성은 불투명도 50%(기록 기간 이동에서 다음 기간이 없을 때). 카드 안에서는 `surface-soft` 동그라미를 쓴다.
- 포커스는 `primary-deep` 3px 윤곽.
