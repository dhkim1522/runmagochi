# TabBar

아래 탭 4개(러닝·기록·아바타·상점). 흰 띠 위에 선택 탭만 어두운 알약.

- 바탕 `surface`, 선택 탭 `panel` 알약 + `on-panel` 아이콘·라벨 13/700, 나머지 `ink-muted` 13/600.
- 탭 칸 높이 56 이상. 키보드 포커스는 `primary-deep` 3px 윤곽.
- 아이콘은 일반 아이콘 세트가 아니라 앱 고유 그림이다(러닝화, 기록 막대, 병아리 얼굴, 코인 주머니). 앱은 `TabIcon` 이 코드로 그린다. 이 견본의 선 그림은 같은 모양을 SVG 로 옮긴 것이다.
- 탭도 버튼처럼 누르면 0.97 로 작아졌다 돌아오고, 선택 바뀜은 `duration-quick`.
