# Button

높이 60 알약 버튼 세 가지: 연두 주요, 흰 보조, 어두운 판.

- 주요(`primary`): 화면마다 하나. 글자 `on-primary`(흰 글자 금지). 면 둘레에 `primary-edge` 2px 경계선 — 연두 면은 바탕과 1.2:1 이라 이 선이 모양을 보인다.
- 보조(`surface` + `ink`): `line-strong` 2px 경계선.
- 어두운 판(`panel` + `on-panel`): 러닝 중 일시정지·재개. 다크에서는 밝은 판.
- 글자 `button`(22/700). 길면 줄을 바꾸지 않고 버튼 안에서 줄어든다.
- 누르면 `duration-press` 80ms 로 살짝 작아졌다(0.97) 돌아온다. 짧게 톡 눌러도 이만큼은 눌린 모양이 남는다. 애니메이션 줄이기면 누른 동안만. 립·그림자 없음.
- 작은 버튼(높이 48, 글자 `body-strong` 17): 주요 버튼 옆 보조 행동(끝부분 잘라내기).
- 비활성은 불투명도 50%.
