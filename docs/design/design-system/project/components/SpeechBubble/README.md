# SpeechBubble

무대 위 캐릭터가 말하는 한 줄. 홈 무대 오른쪽 위, 첫 실행 무대에 쓴다.

- 판은 `bubble`, 모서리 `radius-md` 20, 안쪽 여백 위아래 10 · 좌우 `space-4` 16. 글자는 `label` 14 를 700 으로, `ink`.
- 판 아래 왼쪽(판 왼쪽 끝에서 28)에 16×8 꼬리. 꼬리 끝은 살짝 둥글다.
- `bubble` 은 라이트에서 흰색, 다크에서 하늘보다 밝은 판이다. 다크 `surface` 는 `stage-sky` 와 톤이 같아(ΔE76 8) 모양이 묻혀서 따로 둔다. 위 `ink` 는 다크에서도 7.0:1.
- 한 줄로 두고, 무대가 좁으면 줄을 바꾸지 않고 작아진다. 문구는 앱의 기존 문구만.
