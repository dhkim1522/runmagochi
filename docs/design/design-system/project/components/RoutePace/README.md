# RoutePace

요약·공유 카드의 경로 선. 1km 구간 페이스를 3단 색으로 칠한다.

- 이 러닝의 가장 느린·빠른 구간 사이를 셋으로 나눈다: `pace-slow` 파랑, `pace-mid` 초록, `pace-fast` 주황. 선 6px, 둥근 끝.
- 세 색은 흰 카드 위 3:1 이상이고, 적색맹·녹색맹·청색맹 흉내에서도 서로 구분된다(초록 안에서 밝기만 바꾸지 않았다).
- 구간이 1개 이하이거나 모두 같으면 한 색 `primary-deep`. 빠른 이동 구간은 `ink-muted` 점선.
- 시작 점 `primary` + `on-primary` 테두리, 끝 점 `panel` + `surface` 테두리.
- 색만으로 뜻을 전하지 않는다: 아래 범례를 함께 둔다.
