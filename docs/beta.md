# 베타 배포

베타는 릴리스 APK를 직접 공유한다. Play 내부 테스트와 iOS TestFlight 는 페이즈 8에서 한다.

## 1. 서명 키 만들기

키는 한 번만 만든다. 같은 키로 서명해야 테스터가 덮어 설치로 업데이트할 수 있다.

```
keytool -genkey -v -keystore ~/runmagochi-upload.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
```

`android/key.properties` 를 만든다. 값은 자기 것으로 바꾼다.

```
storePassword=<키스토어 비밀번호>
keyPassword=<키 비밀번호>
keyAlias=upload
storeFile=C:/Users/<이름>/runmagochi-upload.jks
```

- `key.properties`, `*.jks`, `*.keystore` 는 `.gitignore` 에 있다. 절대 커밋하지 않는다.
- 키 파일과 비밀번호는 비밀번호 관리자에 넣고, 클라우드에도 한 벌 보관한다.
- 회사 Mac과 집 Windows PC에서 같은 키를 쓴다. 각 PC에 파일을 복사하고 `key.properties` 의 `storeFile` 경로만 고친다.
- 키를 잃으면 직접 설치한 사용자는 앱을 지우고 새로 설치해야 한다. 기록이 사라진다.
- Play에 올릴 때도 같은 키를 업로드 키로 쓴다. Play 앱 서명을 켜 두면 업로드 키를 잃어도 재설정할 수 있다.
- `key.properties` 가 없으면 디버그 서명으로 빌드된다. 혼자 확인할 때만 쓴다. 테스터에게 보낼 APK는 반드시 릴리스 키로 서명한다.

## 2. 베타 APK 만들기

```
fvm flutter build apk --release
```

결과 파일은 `build/app/outputs/flutter-apk/app-release.apk` 이다.

- 카카오톡이나 구글 드라이브로 파일을 보낸다.
- 테스터는 "출처를 알 수 없는 앱 설치"를 허용해야 한다.
- 업데이트는 같은 서명 키로 만든 APK를 덮어 설치한다. 데이터는 유지된다.
- 베타 빌드를 새로 보낼 때마다 `pubspec.yaml` 의 `version` 뒤 빌드 번호(+N)를 올린다. 번호가 같거나 낮으면 덮어 설치가 안 되고, 올려야 빌드끼리 구분된다. 지금은 `0.3.0+3` 이다. 앞쪽 버전(`0.3.0`)을 바꾸면 설정 화면에 보이는 `lib/core/app_info.dart` 의 `appVersion` 도 같이 고친다.

## 3. 테스터 안내문

아래를 그대로 복사해 보낸다.

```
[러닝 아바타 앱 베타 테스트 안내]

실제로 달린 기록(GPS·페이스)으로 도트 캐릭터를 키우는 러닝 앱이에요.
2주 동안 써 보시고 느낀 점을 알려 주세요.

설치 방법
1. 보내드린 APK 파일을 누릅니다.
2. "출처를 알 수 없는 앱 설치" 허용 안내가 나오면 허용합니다.
3. 설치 후 앱을 엽니다.

허용해 주세요
- 위치: "앱 사용 중 허용" (러닝 경로와 거리를 재기 위해 필요해요)
- 알림: 허용 (러닝 중 표시와 금요일 알림에 쓰여요)
- 배터리: 러닝 중 기록이 끊기면 설정에서 이 앱을 "배터리 최적화 제외"로 바꿔 주세요.

2주 동안 해 봐 주세요
- 주 2~3회 러닝(걷다 뛰다 포함)
- 처음 실행해서 캐릭터 만나기
- 금요일에 오는 알림 확인
- 러닝 요약 화면에서 끝부분 잘라내기 써 보기
- 설정에서 백업 내보내기 해 보기

문제가 생기면 화면을 캡처해서 알려 주세요.
```

## 4. 의견 질문 목록

2주가 지난 뒤 묻는다.

1. 아바타 때문에 다시 달리고 싶어졌나요?
2. 첫 1~2주 동안 캐릭터에 애착이 생겼나요? 언제 느꼈나요?
3. 걷다 뛰다 안내가 달리기 부담을 줄여 주었나요?
4. 기록한 거리가 실제와 얼마나 달랐나요? (다른 앱이나 시계와 비교해서)
5. 배터리가 평소보다 많이 닳았나요?
6. 알림이 귀찮았나요? 언제 오면 좋을까요?
7. 어떤 캐릭터였고 마음에 들었나요?
8. 돈을 내고 살 만한 꾸미기가 있다면 무엇인가요?
9. 가장 불편했거나 헷갈렸던 화면은 어디인가요?
10. 그만두었다면 이유가 무엇인가요?

## 5. 의견 모으는 방법

- 위 질문으로 구글 폼을 하나 만들거나, 카톡 답장으로 받는다.
