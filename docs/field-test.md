# 실기기 실측 안내

> 페이즈 7 의 사람 확인을 기기별로 묶은 안내문. 결과는 `docs/plans/phase-7.md` "사람 확인" 에 옮겨 체크한다. iPhone 설치는 `docs/ios.md`, Android 베타 APK 는 `docs/beta.md`.

## 준비

| 기기 | 설치 | 설정 |
| --- | --- | --- |
| iPhone | `docs/ios.md` "iPhone 에 설치하기" (7일마다 재설치) | 위치 '앱을 사용하는 동안' + 정확한 위치, 알림 허용 |
| Android(가족 폰) | 릴리스 키로 서명한 APK (`docs/beta.md`) | 위치 '앱 사용 중 허용', 알림 허용, 배터리 최적화 제외 |

- 러닝 전 배터리 %를 적어 둔다.
- 앱을 지우면 기록이 사라진다. 지우기 전에 설정 → 백업.

## A. 거리 정확도: 30분 러닝 3회

트랙 400m × N바퀴(실제 거리 = 400 × 바퀴 수)로 달린다. 3회 중 최소 1회는 화면을 끄고 주머니에 넣은 채로 한다.

| 기기 | 회차 | 날짜 | 시간 | 실제 거리(m) | 앱 거리(m) | 오차(%) | 누락(0/1) | 메모(화면 끔·이어폰 등) |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| iPhone | 1 | | | | | | | |
| iPhone | 2 | | | | | | | |
| iPhone | 3 | | | | | | | |
| Android | 1 | | | | | | | |
| Android | 2 | | | | | | | |
| Android | 3 | | | | | | | |

- 오차(%) = (앱 거리 − 실제 거리) ÷ 실제 거리 × 100. 통과: 절댓값 5 이하, 누락 0건.
- 누락은 중간에 기록이 끊기거나 저장되지 않은 경우다.

## B. iPhone 확인 (화면 끈 30분 러닝 중)

- [ ] 상태 막대에 위치 사용 표시가 뜨고 화면을 꺼도 기록이 이어진다 (`CLBackgroundActivitySession` 없이)
- [ ] 이어폰에서 음성 안내가 나오고, 음악이 줄었다가 돌아온다 (화면 꺼짐 포함)
- [ ] 러닝 알림의 거리·시간이 소리 없이 바뀐다. 길게 눌러 일시정지·재개가 된다
- [ ] 멈춰 있으면 종료 예고 알림이 소리와 함께 뜨고 재개 버튼이 된다
- [ ] 시작 직후 정확도 나쁜 점 때문에 첫 구간이 비지 않는다
- [ ] 요약 공유 창에서 "이미지 저장"이 된다. 설정 백업 저장·불러오기가 파일 앱으로 된다
- [ ] 아이콘·스플래시·글꼴·다크 모드 캐릭터 윤곽이 보기 좋다

## C. Android 확인

- [ ] 화면 끈 채 알림창에서 거리·시간이 바뀌고 알림 버튼으로 일시정지·재개가 된다
- [ ] 위치 서비스를 끈 채 시작하면 켜라는 시스템 창이 뜨고 이어진다 (첫 구독 창)
- [ ] 탈것 의심 중 위치를 끄면 "위치 서비스가 꺼져 있어요" 카드가 뜬다 (HANDOFF 결함 후보, 에뮬레이터에서는 재현 안 됨)
- [ ] 다른 기기에서 만든 백업을 가져오면 기록이 복원된다
- [ ] 아이콘·스플래시·글꼴·화면이 보기 좋다

## D. 두 기기 공통

- [ ] 실제 러닝 1회로 경험치 획득부터 레벨업 연출까지 본다 (레벨 1 에서 5km 이상이면 레벨업)
- [ ] 자동 일시정지(멈춤 감지)와 자동 재개 기준이 체감과 맞는다
- [ ] 러닝 전후 배터리: `distanceFilter 0`(1초마다 위치)로 30분에 몇 % 닳는지 적는다. 기준: 받아들일 만한가(사용자 판단)
- [ ] 차·버스로 5분 이상 이동: 시속 22km 초과 30초 평균에 탈것 의심, 의심 합계 2분에 자동 종료(결정 0033).

## E. 기준값 조정 표

실측하고 고칠 값이 있으면 적는다. 바꿀 때는 해당 명세와 결정을 함께 고친다.

| 값 | 지금 | 위치 | 실측 | 바꿀 값 |
| --- | --- | --- | --- | --- |
| 탈것 의심 속도 | 시속 22km, 30초 평균 | `vehicleSpeedMps`·`vehicleWindow` | | |
| 탈것 합계 종료 | 2분 | `autoEndVehicle` | | |
| 신호 끊김 | 점 30초 없음 | `signalLostAfter` | | |
| 자동 일시정지 종료 | 5분 + 예고 30초 | `autoEndStill` | | |
| 부정확한 점 버림 | 정확도 20m 초과 | `docs/specs/run-engine.md` | | |
