# 앱 이름 후보와 상표·스토어 검색

> **앱 이름은 런마고치로 정했다 (결정 0025).** 아래 후보는 상표 충돌 시 대안이다.

> 펫 러너 앱의 이름 후보 6개를 정하고 스토어·도메인 충돌을 웹으로 점검했다. 상표(KIPRIS)는 조회하지 못해 전부 `미확인` 이며 사람이 직접 확인해야 한다.

## 기준

- 달릴수록 자라는 펫, 도트, 따뜻하고 귀여운 톤에 어울린다.
- 소리 내어 말하기 쉽고 한글·영문 표기가 짧다.
- "다마고치", "-gotchi" 계열 표현을 쓰지 않는다 (결정 0012).
- 시장조사(`docs/research/market.md`)의 경쟁 앱 이름과 겹치지 않는다.

- 안드로이드 패키지 이름(`com.*`) 충돌은 전 후보 `미확인`.
- "미등록 추정" 은 DNS 이름 서버 조회에서 응답이 없다는 뜻이며 실제 등록 가능 여부는 `미확인`.
- 웹 검색은 미국 기준 일반 검색이라 스토어 내부 검색을 대체하지 못한다. "발견 안 됨" 은 "없음" 이 아니다.
- KIPRIS 는 화면 입력 후 결과를 보여주는 방식이라 도구로 조회하지 못했다 ([KIPRIS](https://www.kipris.or.kr/khome/main.do)).
- 시장조사 경쟁 앱 이름(딴딴, VirtuPet, Run&Grow 등)과 겹치는 후보는 없다.
- 총총·콩닥·통통·달콩은 흔한 말이라 이미 등록된 상표와 겹치거나 식별력이 약해 등록이 어려울 수 있다. `미확인`.

## 추천

1. **달롱 (Dallong)**
   - 도메인 세 곳이 모두 비어 있는 것으로 보인다.
   - 사전에 없는 말이라 상표 식별력이 높고 경쟁 앱 이름과도 멀다.
   - "달리다" 가 들어가 러닝 앱임이 드러난다.
2. **폴짝 (Poljjak)**
   - 펫이 자라며 뛰어오르는 이미지가 콘셉트와 가장 맞다.
   - `.app` 도메인이 비어 있는 것으로 보인다. `.com`·`.kr` 은 사용 중이라 다른 서비스와 혼동될 수 있다.
