# 스프라이트 규격

아바타는 레이어를 겹쳐 그린다. 실제 에셋은 같은 이름의 파일로 교체하면 되고, 코드는 고치지 않는다.

## 프레임과 시트

- 프레임은 32×32px 이다. 동작마다 프레임을 가로 한 줄로 이은 시트 하나를 쓴다. 시트 크기는 `(프레임 수 × 32) × 32` 이다.
- 투명 배경 PNG. 팔레트 제한은 없다.

| 동작 | 프레임 수 | fps |
|---|---|---|
| idle | 2 | 4 |
| walk | 4 | 6 |
| run | 4 | 10 |

## 레이어

아래에서 위 순서: `body`, `face`, `bottom`, `top`, `shoes`, `hat`, `accessory`. 페이즈 2는 `body`·`face` 만 쓴다.

- body: 외형 단계 1~4 (`stage1` ~ `stage4`). 단계가 오를수록 키가 커진다.
- face: 표정 `normal`·`sleepy`·`asleep`. face 는 종류마다 따로 있고, 한 종류 안에서는 4개 단계가 공유한다. 한 종류의 4개 단계는 머리·눈 위치를 같게 유지한다.
- hat·accessory: 상점 아이템(모자 `cap`·`beanie`·`straw_hat`, 소품 `sunglasses`·`headphones`·`flower_pin`). 아이템마다 종류별 그림이 있고, 한 종류 안에서는 4개 단계가 공유한다(파일 이름에 단계가 없다). 모자 그림에는 종류의 표시(볏·잎·꼭지)가 들어가 종류마다 다르다. 목록은 `lib/shop/domain/catalog.dart`.

## 파일 이름

`assets/sprites/<종류>/<레이어>/<이름>_<동작>.png` (종류: `chick`·`jelly`·`acorn`, 결정 0011)

- 예: `chick/body/stage1_run.png`, `acorn/face/sleepy_idle.png`, `jelly/hat/cap_walk.png`, `chick/accessory/sunglasses_idle.png`
- 아이템 레이어 폴더는 부위 이름(`hat`·`accessory`), 이름은 아이템 id 다.
- 경로는 `lib/avatar/ui/sprite_sheet.dart` 의 `bodySheet`·`faceSheet`·`itemSheet` 가 만든다.

## 기준점

모든 레이어가 같은 기준점을 쓴다. 발끝은 프레임 아래에서 2px 위(y=29)에 둔다. 레이어끼리 따로 어긋나지 않게 한다.

face 레이어는 4개 외형 단계가 모두 공유한다. 그래서 어느 단계의 body 든 머리·눈이 프레임 안에서 같은 위치에 있어야 한다 (실제 아트 교체 시 반드시 지킨다).

아이템 레이어도 face 와 같은 머리 오프셋으로 프레임마다 위아래로 움직인다. 종류마다 기준점 두 개를 둔다.

| 종류 | 모자 기준점 | 소품 기준점 |
|---|---|---|
| chick | 가로 가운데 x=16, 챙 아랫줄 y=18 | x=16, 눈 윗줄 y=20 |
| jelly | x=16, y=18 | x=16, y=20 |
| acorn | x=16, y=17 (도토리 모자 아랫줄) | x=16, y=20 |

- 모자는 눈(y=20·21)을 가리지 않는다.
- 4단계 헤어밴드(병아리·젤리 y=17·18, 도토리 모자 바로 아래 y=18·19, 3종 모두 두 줄)는 모자에 가려도 된다.
- 아이템은 4개 단계가 한 장을 쓰므로 가장 큰 4단계 머리에 맞춘다(페이즈 6 작업 5).
  - 모자는 챙 줄과 그 위의 몸을 4단계 모두 덮는다. 모자 폭은 24칸(밀짚모자 28칸)이고, 4단계 머리는 가장 넓을 때 x=5..26 이다. 그래서 1단계에서는 모자가 머리보다 크다.
  - 모자 위로 보이는 병아리 볏·젤리 잎·도토리 꼭지는 몸이 아니라 종류의 `PetKind.hatSprout` 그림이다. 모자 뒤에 그려 모자 밖으로 나온 부분만 보인다. 그래서 1~4단계 모두 모자 위 모습이 같다(1단계 알도 볏이 나온다).
  - 러닝 캡 챙 가운데는 기준점보다 1줄 아래(병아리·젤리 y=19, 도토리 y=18)까지 휘어 내려온다. 눈은 가리지 않는다.
  - 헤드폰 귀덮개(y=20~22)는 1단계 머리 옆에 붙고 4단계 머리 밖으로 1칸 나온다. 머리띠는 머리 위를 가로질러 젤리 1·2단계 잎을 덮는다.

## 화면 표시

정수 배율로 키우고 `FilterQuality.none` 으로 그린다.

## 만드는 방법

그림은 코드 안의 데이터다(작업 9, 페이즈 6 실제 아트 전까지).

- `tool/sprites/<kind>.dart` (chick·jelly·acorn): 단계별 기본 그림(몸 + 장비, 눈 없음)과 표정 그림. 한 글자가 한 픽셀이고 색은 `tool/sprites/pet_art.dart` 의 팔레트에서 찾는다.
- `tool/sprites/pet_art.dart`: 자세표로 기본 그림에서 idle·walk·run 프레임을 만든다. 머리가 움직인 만큼 face 프레임도 같이 움직이므로 4단계가 face 를 함께 쓸 수 있다. 1단계 알(병아리)은 걷기·달리기 대신 통통 튄다.
  - 자세표는 3종이 같이 쓴다. 숨쉬기·달리기는 머리를 늘이기만 한다(눌림은 `squashRow` 줄을 지운다). 달리기는 뜰 때 머리가 2px 오르고 팔을 ±2 흔든다.
- 그림체(페이즈 6, 후보 a 말랑 클레이): 빛은 왼쪽 위, 3단 명암(하이라이트·기본·그림자), 진한 외곽선 `o`. 3종이 같은 그림체다.
  - 병아리 `l`·`m`·`M`(알 `q`·`y`·`Y`), 젤리 `i`·`b`·`B`(왼쪽 위 반짝임 `h`, 외곽선 두른 잎 두 장), 도토리 몸 `t`·`n`·`N`, 모자 `x`·`C`·`c`(`c` 비늘 무늬).
  - 날개·팔·러닝화는 3종 모두 `clayArmRows`·`clayShoeFoot`. 젤리·도토리 1단계는 작은 발(`nubFoot`)로 걷고, 병아리 1단계 알만 통통 튄다.
  - 표정: 3종의 눈(y=20·21)은 같다. 졸린 눈꺼풀은 바깥으로 처진다(안쪽으로 내려오면 화난 눈처럼 보인다). 젤리·도토리의 입은 face 의 y=22 한 줄, 병아리 부리는 body 에 있다.
  - 4단계 메달은 3종 모두 목 아래 가로 끈(y=25)에 매단다. 입·부리 바로 아래 세로 끈은 입처럼 보인다.
  - 젤리 잎 두 장은 좌우 대칭이다(오른쪽 잎은 왼쪽 잎을 뒤집은 색).
  - 아이템도 같은 그림체다. 3단 명암: 캡 `H`·`T`·`W`(챙 `U`), 비니 `I`·`v`·`V`, 밀짚 `F`·`s`·`S`(띠 `d`·`D`), 선글라스 알 `J`·`L`(반짝임 `w`), 헤드폰 머리띠 `X`·`u`·`Z`·귀덮개 `Q`·`R`·`d`, 꽃 `P`·`f`·`K`(꽃술 `e`·`E`).
- 장비(결정 0013): 1단계 없음, 2단계 러닝화, 3단계 + 손목 밴드, 4단계 + 헤어밴드 + 완주 메달.
- `tool/sprites/items.dart`: 아이템 그림 6장. 그림 한 장을 종류의 기준점(`PetKind.hatAnchor`·`accessoryAnchor`)에 가운데 맞춰 놓는다. 모자는 종류의 `hatSprout` 를 뒤에 함께 그린다.
- 다시 만들기: `fvm dart run tool/render_sprites.dart` — 아래 파일을 쓴다.
  - `assets/sprites/**` 시트
  - `design/character/<kind>.png` 8배 미리보기: 줄 = 단계, 칸 = idle·walk·run 프레임, 마지막 줄 = 표정
  - `design/character/items.png` 8배 아이템 미리보기: 줄 = 아이템 없음 + 아이템 6개, 칸 = 종류 3 × 단계 1~4
- 콘셉트 한 장: `fvm dart run tool/render_concepts.dart` — `design/character/concepts.png`(3종 × 1·4단계 idle). 그림은 위 펫 데이터에서 가져온다.
- 검사: `test/tool/sprite_data_test.dart`
  - 프레임 형식, face 가 4단계 몸 위에 있음, 프레임끼리 다름, 발끝 y=29·공중 y=28, 단계별 장비
  - 자세표는 머리를 늘이기만 함, 3종 3단 명암·기본 그림 줄 너비·메달 끈 y=25·표정 눈 자리(3종 같은 눈, 졸린 눈꺼풀은 바깥으로)
  - 아이템 프레임 형식, 아이템 세로 이동 = face 세로 이동, 모자가 face 를 가리지 않음
  - 모자가 4단계 모두 챙 줄과 그 위의 몸을 덮음, 헤드폰 귀덮개가 머리 옆에 붙고 머리 밖으로 나옴, 선글라스가 눈을 덮음
  - 3종 4단계 헤어밴드가 눈 위 두 줄, 젤리 잎 좌우 대칭
