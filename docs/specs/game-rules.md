# 게임 규칙 명세

> 경험치·레벨·성장 단계·코인·배지의 계산 규칙과 수치. 모든 계산은 앱 안에서 한다. 수치는 초안이며 베타 테스트에서 조정한다.

## 경험치와 레벨

- **경험치**: 1km당 10. 러닝 목표 달성 시 +20
- **레벨**: 레벨 n에서 n+1로 가는 데 필요한 경험치 = 50 × n
- **체감 속도**: 주 3회 5km를 달리면 초반엔 매주 1~2레벨, 10레벨 이후엔 2~3주에 1레벨

## 성장 단계

누적 거리 기준으로 외형이 크게 바뀐다.

| 단계 | 누적 거리 | 외형 |
| --- | --- | --- |
| 1 | 0~50km | [알·새싹] |
| 2 | 50~250km | [어린 러너] |
| 3 | 250~1,000km | [러너] |
| 4 | 1,000km 이상 | [마라토너] |

## 코인

| 사유 | 지급량 |
| --- | --- |
| 거리 | 1km당 5 |
| 러닝 목표 달성 | 30 |
| 주간 목표 달성 | 100 |
| 연속 러닝 | 연속 일수 × 5, 최대 50 |
| 배지 달성 | 배지마다 50~300 |

아이템 기본 가격은 100~400코인이다. 5km 러닝 1회(약 55코인)로 2~4회마다 아이템 1개를 살 수 있게 맞춘다.

## 기록 검사

- **하루 상한**: 코인 300, 경험치 300
- **속도 검사**: 1km 구간 페이스가 2분30초보다 빠르면 그 구간은 보상에서 뺀다. 자전거·차량 이동을 막는다.
- **수동 입력 기록**: 기록은 남기되 보상은 주지 않는다.

기기에서 계산하므로 기기 조작까지 막지는 못한다. 서버 검증은 [서버 이전 경로](../architecture.md#서버-이전-경로) 3단계에서 추가한다.
